# Лабораторная работа №6. Обработка и валидация форм

## Цель работы

Освоить основные принципы работы с HTML-формами в PHP, включая отправку данных на сервер и их обработку, включая валидацию данных. Реализовать решение с использованием объектно-ориентированного программирования.

---

## Тема проекта

**HabitFlow — Трекер привычек.**

Приложение позволяет вести учёт выполнения ежедневных привычек: добавлять записи о прогрессе, редактировать их и удалять. Список записей отображается в виде таблицы с возможностью сортировки по любому полю.

## Шаг 1. Определение модели данных

Для темы «Трекер привычек» определена следующая модель данных:

| Поле            | Тип    | Описание                                                    |
|-----------------|--------|-------------------------------------------------------------|
| `id`            | string | Уникальный идентификатор записи                             |

| `used_reminder` | bool   | Флаг: использовалось ли напоминание (checkbox)              |
| `created_at`    | string | Дата и время создания записи (заполняется автоматически)    |

## Шаг 3. ООП-реализация

### Класс `HabitEntry`

Модель данных одной записи о привычке. Содержит все поля и два статических фабричных метода для преобразования данных.

```php
<?php

/**
 * Модель одной записи о выполнении привычки.
 */
class HabitEntry
{
    /** @var string Уникальный идентификатор */
    public string $id;

    /** @var string Название привычки */
    public string $habit_name;

    /** @var string Категория: health|sport|learning|productivity|other */
    public string $category;

    /** @var string Дата выполнения (YYYY-MM-DD) */
    public string $date;

    /** @var string Затраченное время в минутах */
    public string $duration_min;

    /** @var string Статус: completed|partial|skipped */
    public string $status;

    /** @var string Заметки о выполнении */
    public string $notes;

    /** @var bool Использовалось ли напоминание */
    public bool $used_reminder;

    /** @var string Дата и время создания записи */
    public string $created_at;

    /**
     * Создаёт объект из массива данных (например, из $_POST или из файла).
     *
     * @param array $data Ассоциативный массив с данными записи
     * @return self
     */
    public static function fromArray(array $data): self
    {
        $entry               = new self();
        $entry->id           = $data['id']           ?? uniqid();
        $entry->habit_name   = trim($data['habit_name']   ?? '');
        $entry->category     = $data['category']     ?? 'other';
        $entry->date         = $data['date']         ?? '';
        $entry->duration_min = trim($data['duration_min'] ?? '');
        $entry->status       = $data['status']       ?? 'completed';
        $entry->notes        = trim($data['notes']        ?? '');
        $entry->used_reminder = !empty($data['used_reminder']);
        $entry->created_at   = $data['created_at']   ?? date('Y-m-d H:i:s');
        return $entry;
    }

    /**
     * Конвертирует объект в массив для сохранения в JSON.
     *
     * @return array
     */
    public function toArray(): array
    {
        return [
            'id'           => $this->id,
            'habit_name'   => $this->habit_name,
            'category'     => $this->category,
            'date'         => $this->date,
            'duration_min' => $this->duration_min,
            'status'       => $this->status,
            'notes'        => $this->notes,
            'used_reminder'=> $this->used_reminder,
            'created_at'   => $this->created_at,
        ];
    }
}
```

### Класс `HabitValidator`

Отвечает исключительно за валидацию данных. Принимает массив из `$_POST`, возвращает список ошибок. Если список пустой — данные корректны.

```php
/**
 * Валидатор данных записи о привычке.
 * Возвращает список ошибок; если список пустой — данные корректны.
 */
class HabitValidator
{
    /** @var string[] Допустимые категории привычек */
    private const VALID_CATEGORIES = ['health', 'sport', 'learning', 'productivity', 'other'];

    /** @var string[] Допустимые статусы выполнения */
    private const VALID_STATUSES = ['completed', 'partial', 'skipped'];

    /**
     * Проверяет массив данных и возвращает массив ошибок.
     *
     * @param array $data Данные из формы
     * @return string[] Массив сообщений об ошибках (пустой, если ошибок нет)
     */
    public function validate(array $data): array
    {
        $errors = [];

        if (empty(trim($data['habit_name'] ?? ''))) {
            $errors[] = 'Укажите название привычки.';
        } elseif (strlen($data['habit_name']) > 100) {
            $errors[] = 'Название не должно превышать 100 символов.';
        }

        if (!in_array($data['category'] ?? '', self::VALID_CATEGORIES, true)) {
            $errors[] = 'Выберите допустимую категорию.';
        }

        if (empty($data['date'] ?? '')) {
            $errors[] = 'Укажите дату выполнения.';
        } elseif (!$this->isValidDate($data['date'])) {
            $errors[] = 'Дата имеет неверный формат.';
        }

        $duration = $data['duration_min'] ?? '';
        if ($duration === '') {
            $errors[] = 'Укажите затраченное время.';
        } elseif (!ctype_digit((string)$duration) || (int)$duration < 1 || (int)$duration > 1440) {
            $errors[] = 'Время должно быть целым числом от 1 до 1440 минут.';
        }

        if (!in_array($data['status'] ?? '', self::VALID_STATUSES, true)) {
            $errors[] = 'Выберите допустимый статус выполнения.';
        }

        if (empty(trim($data['notes'] ?? ''))) {
            $errors[] = 'Добавьте заметку о выполнении.';
        } elseif (strlen($data['notes']) < 10) {
            $errors[] = 'Заметка слишком короткая (минимум 10 символов).';
        }

        return $errors;
    }

    /**
     * Проверяет, является ли строка корректной датой формата YYYY-MM-DD.
     *
     * @param string $date Строка с датой
     * @return bool
     */
    private function isValidDate(string $date): bool
    {
        $d = DateTime::createFromFormat('Y-m-d', $date);
        return $d && $d->format('Y-m-d') === $date;
    }
}
```

### Класс `HabitStorage`

Отвечает за чтение и запись данных в JSON-файл. Реализует полный набор операций: загрузка всех записей, добавление, обновление, удаление и поиск по ID.

```php
/**
 * Хранилище записей о привычках: читает и пишет JSON-файл.
 */
class HabitStorage
{
    /** @var string Путь к файлу с данными */
    private string $file;

    /**
     * @param string $file Путь к JSON-файлу
     */
    public function __construct(string $file = 'data.json')
    {
        $this->file = $file;
    }

    /**
     * Загружает все записи из файла.
     *
     * @return HabitEntry[]
     */
    public function loadAll(): array
    {
        if (!file_exists($this->file)) {
            return [];
        }
        $raw = json_decode(file_get_contents($this->file), true) ?? [];
        return array_map(fn($item) => HabitEntry::fromArray($item), $raw);
    }

    /**
     * Сохраняет список записей в файл.
     *
     * @param HabitEntry[] $entries
     * @return void
     */
    public function saveAll(array $entries): void
    {
        $data = array_map(fn($entry) => $entry->toArray(), $entries);
        file_put_contents(
            $this->file,
            json_encode(array_values($data), JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE)
        );
    }

    /**
     * Добавляет одну запись и сохраняет файл.
     *
     * @param HabitEntry $entry
     * @return void
     */
    public function add(HabitEntry $entry): void
    {
        $all   = $this->loadAll();
        $all[] = $entry;
        $this->saveAll($all);
    }

    /**
     * Обновляет существующую запись по ID.
     *
     * @param HabitEntry $updated Обновлённый объект
     * @return bool true если найдено и обновлено
     */
    public function update(HabitEntry $updated): bool
    {
        $all = $this->loadAll();
        foreach ($all as $i => $entry) {
            if ($entry->id === $updated->id) {
                $updated->created_at = $entry->created_at;
                $all[$i] = $updated;
                $this->saveAll($all);
                return true;
            }
        }
        return false;
    }

    /**
     * Удаляет запись по ID.
     *
     * @param string $id
     * @return bool true если найдено и удалено
     */
    public function delete(string $id): bool
    {
        $all      = $this->loadAll();
        $filtered = array_filter($all, fn($entry) => $entry->id !== $id);
        if (count($filtered) === count($all)) {
            return false;
        }
        $this->saveAll($filtered);
        return true;
    }

    /**
     * Находит запись по ID.
     *
     * @param string $id
     * @return HabitEntry|null
     */
    public function findById(string $id): ?HabitEntry
    {
        foreach ($this->loadAll() as $entry) {
            if ($entry->id === $id) return $entry;
        }
        return null;
    }
}
```

## Шаг 4. Создание HTML-формы и обработка данных на сервере

Файл `form.php` выполняет сразу две роли: отображает форму (для создания и для редактирования) и обрабатывает её отправку. Режим определяется наличием параметра `id` в запросе.

```php
<?php
session_start();
require_once 'classes.php';

$storage   = new HabitStorage('data.json');
$validator = new HabitValidator();

$editId = $_GET['id'] ?? $_POST['id'] ?? null;
$isEdit = $editId !== null;
$errors = [];

// При редактировании — предзаполняем форму данными из файла
if ($isEdit && $_SERVER['REQUEST_METHOD'] !== 'POST') {
    $existing = $storage->findById($editId);
    if (!$existing) {
        header('Location: index.php');
        exit;
    }
    $data = $existing->toArray();
} else {
    $data = $_POST ?: [];
}

// Обработка отправки формы
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $errors = $validator->validate($data);

    if (empty($errors)) {
        $entry = HabitEntry::fromArray($data);

        if ($isEdit) {
            $storage->update($entry);
            $_SESSION['flash'] = ['type' => 'success', 'msg' => 'Запись обновлена!'];
        } else {
            $storage->add($entry);
            $_SESSION['flash'] = ['type' => 'success', 'msg' => 'Привычка добавлена!'];
        }

        header('Location: index.php');
        exit;
    }
}

 * Безопасно возвращает значение поля для вывода в HTML.
 *
 * @param array  $data Массив данных
 * @param string $key  Ключ поля

function val(array $data, string $key): string {
    return htmlspecialchars($data[$key] ?? '');
}

 */
function sel(array $data, string $key, string $value): string {
    return ($data[$key] ?? '') === $value ? 'selected' : '';
}
```

## Шаг 5. Вывод данных и сортировка

Файл `index.php` загружает все записи из файла и сортирует их по выбранному полю. Параметры сортировки передаются через GET-запрос (`?sort=date&dir=asc`). Допустимые значения проверяются белым списком, чтобы исключить подстановку произвольных имён полей.

```php
<?php
session_start();
require_once 'classes.php';

$storage = new HabitStorage('data.json');
$entries = $storage->loadAll();

$sortField    = $_GET['sort'] ?? 'date';
$sortDir      = $_GET['dir']  ?? 'desc';
$allowedSorts = ['date', 'habit_name', 'category', 'status', 'duration_min', 'created_at'];

if (!in_array($sortField, $allowedSorts, true)) $sortField = 'date';
if (!in_array($sortDir, ['asc', 'desc'], true)) $sortDir = 'desc';

usort($entries, function ($a, $b) use ($sortField, $sortDir) {
    $cmp = strcmp($a->$sortField, $b->$sortField);
    return $sortDir === 'asc' ? $cmp : -$cmp;
});

/**
 * Формирует URL для сортировки по заданному полю с переключением направления.
 *
 * @param string $field    Поле для сортировки
 * @param string $current  Текущее поле сортировки
 * @param string $dir      Текущее направление сортировки
 * @return string URL с параметрами сортировки
 */
function sortUrl(string $field, string $current, string $dir): string {
    $newDir = ($field === $current && $dir === 'asc') ? 'desc' : 'asc';
    return '?sort=' . urlencode($field) . '&dir=' . $newDir;
}

/**
 * Возвращает стрелку направления сортировки для заголовка таблицы.
 *
 * @param string $field   Поле колонки
 * @param string $current Текущее поле сортировки
 * @param string $dir     Текущее направление
 * @return string Символ стрелки или пустая строка
 */
function sortArrow(string $field, string $current, string $dir): string {
    if ($field !== $current) return '';
    return $dir === 'asc' ? ' ▲' : ' ▼';
}

</div>
</body>
</html>
```

Клик по заголовку столбца переключает направление сортировки. Текущее направление отображается стрелкой рядом с названием столбца.

## Шаг 6. Удаление записи

Файл `delete.php` принимает `id` через GET-параметр, вызывает `$storage->delete($id)` и перенаправляет обратно на главную страницу с flash-сообщением о результате.

```php
<?php
session_start();
require_once 'classes.php';

$id = $_GET['id'] ?? null;

if (!$id) {
    header('Location: index.php');
    exit;
}

$storage = new HabitStorage('data.json');
$deleted = $storage->delete($id);

$_SESSION['flash'] = $deleted
    ? ['type' => 'success', 'msg' => 'Запись удалена.']
    : ['type' => 'error',   'msg' => 'Запись не найдена.'];

header('Location: index.php');
exit;
```

Перед удалением в браузере отображается стандартный диалог подтверждения (`confirm()`), чтобы исключить случайное удаление.

## Контрольные вопросы

### 1. Какие существуют методы отправки данных из формы на сервер? Какие методы поддерживает HTML-форма?

HTML-форма поддерживает два метода, задаваемых атрибутом `method`:

- **GET** — данные передаются в строке URL в виде параметров запроса (`?name=value`). Подходит для поиска и фильтрации, так как результат можно сохранить в закладки. Не подходит для передачи чувствительных данных или больших объёмов информации, так как URL ограничен по длине и виден в адресной строке.
- **POST** — данные передаются в теле HTTP-запроса, не отображаются в URL. Используется для создания и изменения данных, отправки паролей и загрузки файлов.

В данной работе форма использует метод `POST`, так как данные изменяют состояние приложения (создают или обновляют запись). Для сортировки и фильтрации в `index.php` используется метод `GET`, поскольку параметры сортировки не меняют данные и должны сохраняться при обновлении страницы.

---

### 2. Какие глобальные переменные используются для доступа к данным формы в PHP?

PHP предоставляет несколько суперглобальных массивов для доступа к данным запроса:

- **`$_POST`** — содержит данные, отправленные методом POST. Используется в `form.php` для получения значений всех полей формы.
- **`$_GET`** — содержит параметры из строки URL. Используется в `index.php` для параметров сортировки и в `delete.php` / `form.php` для получения `id` редактируемой или удаляемой записи.
- **`$_REQUEST`** — объединяет `$_GET`, `$_POST` и `$_COOKIE`. Удобен, но менее явен относительно источника данных, поэтому в данной работе не применяется.
- **`$_SESSION`** — используется для передачи flash-сообщений между страницами после редиректа.
- **`$_FILES`** — используется при загрузке файлов (в данной работе не применяется).

### 3. Как обеспечить безопасность при обработке данных из формы (например, защититься от XSS)?

**XSS (Cross-Site Scripting)** — атака, при которой злоумышленник внедряет вредоносный JavaScript в страницу через пользовательский ввод. Для защиты применяются следующие меры:

- **Экранирование вывода через `htmlspecialchars()`** — все данные перед выводом в HTML проходят через эту функцию. Она заменяет символы `<`, `>`, `"`, `'`, `&` на соответствующие HTML-сущности, не позволяя браузеру интерпретировать их как код. В данной работе для этого создан хелпер `val()`, который применяется ко всем полям формы и ячейкам таблицы.

```php
function val(array $data, string $key): string {
    return htmlspecialchars($data[$key] ?? '');
}
```

- **Серверная валидация по белым спискам** — данные проверяются по константам допустимых значений (`VALID_CATEGORIES`, `VALID_STATUSES`). Значение, не входящее в список, отклоняется с ошибкой, даже если клиентская валидация была обойдена.

- **Никогда не доверять клиентской валидации** — атрибуты `required`, `maxlength`, `minlength`, `min` и `max` на HTML-элементах улучшают пользовательский опыт, но легко обходятся через инструменты разработчика или прямые HTTP-запросы. Вся критическая проверка выполняется повторно на сервере в классе `HabitValidator`.
